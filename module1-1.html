Module 1.1 : Les types de données

Les différents types de données

Variable quantitative

Une variable quantitative est une variable qui représente une quantité numérique. Elle permet de mesurer ou de compter une caractéristique d'un individu ou d'une population.

Variable quantitative discrète

Une variable quantitative discrète est une variable qui peut prendre seulement certaines valeurs numériques distinctes. Elle est généralement obtenue en faisant un dénombrement et ses valeurs sont souvent des nombres entiers.

Exemples : le nombre de frères et sœurs d'une personne, le nombre d'élèves dans une classe ou le nombre de voitures dans un stationnement.

Variable quantitative continue

Une variable quantitative continue est une variable qui peut prendre n'importe quelle valeur dans un intervalle. Elle est généralement obtenue par une mesure et peut donc prendre des valeurs décimales.

Exemples : la taille d'une personne, son poids, la température ou le temps nécessaire pour courir une certaine distance.

Variable qualitative

Une variable qualitative décrit une caractéristique ou une catégorie plutôt qu'une quantité numérique. Elle permet de classer les individus selon une qualité ou une caractéristique particulière.

Variable qualitative nominale

Une variable qualitative nominale est une variable dont les catégories n'ont pas d'ordre ou de classement particulier. Les catégories servent simplement à identifier ou à différencier les individus.

Exemples : la couleur préférée, le pays d'origine, le type de musique préféré ou la marque de téléphone utilisée.

Variable qualitative ordinale

Une variable qualitative ordinale est une variable dont les catégories peuvent être placées dans un ordre logique. Cependant, la différence entre les catégories ne peut pas nécessairement être mesurée numériquement.

Exemples : le niveau de satisfaction (insatisfait, neutre, satisfait), le niveau de difficulté (facile, moyen, difficile) ou le niveau de douleur (faible, modéré, élevé).

Certains types de diagrammes

Diagramme à bandes

Un diagramme à bandes représente des données à l'aide de bandes rectangulaires. Chaque bande représente une catégorie et sa longueur ou sa hauteur indique la fréquence ou la quantité associée à cette catégorie.

Les bandes sont séparées les unes des autres, car elles représentent des catégories distinctes.

Contexte : On utilise principalement un diagramme à bandes pour comparer différentes catégories. Par exemple, on pourrait comparer le nombre d'élèves qui préfèrent différents sports.

Histogramme

Un histogramme représente la distribution d'une variable quantitative en regroupant les données dans des intervalles appelés classes. Les bandes se touchent puisqu'elles représentent des intervalles continus.

Un histogramme permet de voir comment les données sont distribuées et de repérer leur concentration, leur dispersion et leur forme générale.

Contexte : On peut utiliser un histogramme pour représenter la distribution des tailles des élèves d'une école ou les résultats d'un examen.

Diagramme circulaire

Un diagramme circulaire représente un ensemble de données sous la forme d'un cercle divisé en plusieurs secteurs. Chaque secteur représente une catégorie et sa taille correspond à la proportion de cette catégorie par rapport au total.

Les secteurs sont généralement présentés en pourcentages afin de montrer clairement la répartition des données.

Contexte : On peut utiliser un diagramme circulaire pour représenter les moyens de transport utilisés par les élèves pour se rendre à l'école.

Diagramme à ligne brisée

Un diagramme à ligne brisée représente des données à l'aide de points reliés par des segments de droite. Il permet de montrer les changements et les tendances d'une variable.

Ce type de diagramme est particulièrement utile lorsque les données sont recueillies au fil du temps.

Contexte : On peut utiliser un diagramme à ligne brisée pour représenter l'évolution de la température pendant une semaine ou l'évolution des ventes d'une entreprise au cours de plusieurs mois.
