Module 1.4 : Données de sources primaires et secondaires

Sources de données primaires

Définition : Les données primaires sont des données recueillies directement par une personne ou une organisation dans le but de répondre à une question ou à un objectif précis.

Exemples

  • Questionnaires et sondages
  • Entrevues
  • Observations
  • Expériences
  • Formulaires conçus pour recueillir des données

Les données primaires sont recueillies directement auprès de la source. Elles sont donc adaptées spécifiquement au problème étudié.

Sources de données secondaires

Définition : Les données secondaires sont des données qui ont déjà été recueillies par une autre personne ou organisation et qui sont ensuite utilisées pour une nouvelle étude ou analyse.

Exemples

  • Données de Statistique Canada
  • Articles scientifiques
  • Rapports gouvernementaux
  • Livres et publications
  • Bases de données existantes
  • Sites Web fiables

Contrairement aux données primaires, les données secondaires ne sont pas recueillies directement par le chercheur pour son étude actuelle.
